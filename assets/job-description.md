# Senior .NET Full Stack Developer

## About the Role

We are looking for a Senior .NET Full Stack Developer to join our engineering team. You will be responsible for designing, developing, and maintaining scalable web applications using .NET and modern frontend frameworks.

## Responsibilities

- Design and develop RESTful APIs using ASP.NET Core / .NET 8+
- Build responsive, modern UI with React or Angular
- Write clean, maintainable, testable code following SOLID principles
- Work with SQL Server, Entity Framework Core, and NoSQL databases
- Implement CI/CD pipelines using Azure DevOps or GitHub Actions
- Participate in code reviews, architecture discussions, and sprint planning
- Mentor junior developers and contribute to engineering best practices

## Required Skills

C#, ASP.NET Core, .NET 8, Entity Framework Core, SQL Server, REST API, React or Angular, TypeScript, Git, Azure or AWS, Docker, Unit Testing (xUnit/NUnit), SOLID Principles, Design Patterns

## Preferred Skills

Microservices architecture, Azure Functions, Message Queues (RabbitMQ/Azure Service Bus), Redis, GraphQL, Blazor, Kubernetes, Terraform, Performance Optimization, System Design

## Experience Level

5-8 years of professional experience in .NET development with at least 2 years in a senior or lead capacity.

## Education

Bachelor's degree in Computer Science, Engineering, or related field. Equivalent practical experience is also acceptable.
